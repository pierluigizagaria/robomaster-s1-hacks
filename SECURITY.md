# Security policy

This project controls powered hardware and patches a locally installed desktop
application. Treat unexpected motion, unsafe power behavior, compatibility
mistakes, backup or restore failures, and accidental disclosure of credentials
or device secrets as security issues.

Do not publish an unreviewed proof of concept that can cause uncontrolled robot
motion or defeat independent lithium-cell protection. Open a private GitHub
security advisory, or contact the maintainer
privately through the address listed on their GitHub profile.

Include the affected product, exact robot or application version, observed
behavior, reproduction conditions, and whether the original state can be
restored. Remove tokens, account data, device identifiers, private firmware,
and proprietary binaries from logs before sharing them.

Only the latest release and the exact targets documented by each product are
supported.
